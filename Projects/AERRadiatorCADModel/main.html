Project

AER Radiator CAD Model

This project involved reverse engineering and building a CAD model of the Earl’s 16-row radiator/oil cooler used in our FSAE cooling system. The manufacturer did not provide a CAD model, and the simplified model we had was not accurate enough to run a moderately accurate fluids and thermal simulation. I went about doing the CAD through dimensions from manufacturer images, iteratively redesigning the CAD model, and finally validated the internal volume using Ansys Discovery.

Overview

Problem

The main challenge was that our team needed an accurate radiator/oil cooler CAD model for cooling system analysis, but the manufacturer did not provide one. The simplified model we had was missing geometry, such as the fins, and its internal volume was 0.58 quarts compared to the actual volume of 0.3 quarts, preventing reliable fluid or thermal simulations.

Solution

I developed a new CAD model by extracting dimensions from manufacturer images using a web plot digitizer, then scaling those measurements to the actual core dimensions. Through multiple design iterations, the CAD model became more modular so tube count, fin spacing, and core dimensions can be adjusted more easily in the future. I used Ansys Discovery to extract and compare internal volume across each version, reducing the modeled volume from the original simplified estimate and improving the model’s usefulness for future fluids and thermal analysis. The final model includes all key geometry such as louvered fins and a volume of 0.43 quarts, a volume approximately 26% more accurate than the original model.

Process

Step One / Getting Base Dimensions

Since I did not have the radiator physically available to take measurements, I used a web plot digitizer to extract dimensions from manufacturer images. I then scaled those dimensions to the actual core dimensions to create an initial CAD model.

Step Two / Iterations

The first iteration was of a 19-row core, which was incorrect because we were using a 16-row radiator. After six iterations, the model was refined to use cleaner and less process-intensive CAD methods, such as surface offset and interference for equal thickness along tube walls. The final model includes all key geometry such as louvered fins and a volume of 0.43 quarts.

Step Three / Volume Extraction

The final step after each iteration was to extract the internal volume using Ansys Discovery. The original simplified model had a volume of 0.58 quarts compared to the actual volume of 0.3 quarts, while the final model had a volume of 0.43 quarts, a roughly 26% improvement in volumetric accuracy.
